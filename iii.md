## 2. Defects in the Original Baseline Code (`wp_pds_data_fix`) Addressed for KN-221

Even with the exact code from the screenshots, the legacy `wp_pds_data_fix` package has **5 functional defects** relative to **KN-221** requirements:

1. **Monolithic Coupling & Fatal `NO_DATA_FOUND` Bug (`wp_pds_data_fix.sql` Line 68):**
   * Inside the inner loop (`image_e6dacc.jpg`, line 68), the script runs an unprotected `SELECT AGREE_ID INTO sAgreementId FROM SIEBEL.CX_AGREE_ORG WHERE ACCNT_ID = sPartyId AND (END_DT IS NULL OR END_DT >= sDate);` *before* inserting into `EIM_ACCOUNT`.
   * If a Group Merchant in Scenario I has no active agreement in `CX_AGREE_ORG`, Oracle immediately throws `NO_DATA_FOUND`, jumps to `EXCEPTION WHEN OTHERS` (line 188), marks the row as `'SQL_PROCESSING_ERROR'`, and **never updates the PDS Flag (`EIM_ACCOUNT`) or Role Refresh (`EIM_DEFECT`)**.
2. **Missing Hierarchy Update for Child POs (Scenario I):**
   * In `wp_pds_data_fix.sql`, `curr_rec` only looks up `WHERE org.NAME = sPartyName` (updating `X_WP_PRI_PDS_FLG = 'Y'` only on the parent merchant) and only inserts child POs (`WHERE MASTER_OU_ID = sPartyId`) into `EIM_DEFECT` (line 175). It does **not** set `X_WP_PRI_PDS_FLG = 'Y'` on the child POs in the hierarchy as required by KN-221 Acceptance Criteria I (*"PDSFlag is set to Y on every PO in that Group Merchant's hierarchy, at all levels"*).
3. **Missing Skip Condition for Merchants Already Set to `'Y'` (Scenario I):**
   * The legacy script updates `EIM_ACCOUNT` and triggers `EIM_DEFECT` Role Refresh even if `org.X_WP_PRI_PDS_FLG` is already `'Y'`, violating KN-221 (*"Merchants already set to Y are left unchanged and are not re-refreshed"*).
4. **Duplicate CSV Rows / Hierarchy Overlap Crash:**
   * As seen on screenshot `image_53a2b6.jpg`, `wp_pds_data_fix.csv` contains `PO4001257351` 4 times. In the legacy script, processing the same PO twice in the same batch inserts duplicate `ROW_ID` values into `EIM_ACCOUNT` and `EIM_DEFECT`, causing `ORA-00001: unique constraint violated` and rolling back into `SQL_PROCESSING_ERROR`.
5. **Broken Batch Increment (`ROWNUM` Always 1 in Inner Cursor):**
   * On screenshot `image_cd4630.jpg` (line 30), `3000100 + FLOOR(ROWNUM / 5000)` is evaluated inside `curr_rec` (`WHERE org.NAME = sPartyName`), where `ROWNUM` is always `1` per PO. Using a PL/SQL counter (`v_seq`) fixes batching across 5,000+ rows.

```sql
            PAR_AGREE_ACC_BI,
            PAR_AGREE_ACC_BU,

            sNewDate

            SIEBEL.S_ENTLMNT_ORG ENT_ORG,

            AND ENT_ORG.OU_ID = PARTY.ROW_ID
```

```sql
/*
-------------------------------------------------------------------------------------
-- File: wp_kn221_pds_flag.sql
-- Desc: KN-221 Part I - Populate PDS flag = Y on Group Merchants and all child POs
--       in hierarchy, skip already-'Y' merchants, and stage Role Refresh in EIM_DEFECT
-------------------------------------------------------------------------------------
*/

SET SERVEROUTPUT ON
SET VERIFY OFF
WHENEVER SQLERROR EXIT FAILURE

DECLARE
    counter       NUMBER(9) := 0;
    v_seq         NUMBER(9) := 0;
    sPartyName    VARCHAR2(50);
    sEimRowId     VARCHAR2(15);
    v_exists      NUMBER := 0;
    v_updated_cnt NUMBER := 0;

    CURSOR curr_party IS
        SELECT TRIM(DIS_NAME) AS PARTY_NAME, ROW_ID AS EIM_ROW_ID
        FROM SIEBEL.EIM_DISEASE_DTL
        WHERE IF_ROW_BATCH_NUM = 3000100;

    -- Selects the Group Merchant and all child POs across all levels of its hierarchy
    CURSOR curr_rec IS
        SELECT /*+ opt_param('hash_join_enabled','true') opt_param('optimizer_mode','all_rows') */
            orgparty.PARTY_UID              AS PARTY_UID,
            orgparty.PARTY_TYPE_CD          AS PARTY_TYPE_CD,
            org.NAME                        AS NAME,
            org.LOC                         AS LOC,
            orgbu.ROW_ID                    AS ACCNT_BI,
            orgbu.NAME                      AS ACCNT_BU,
            NVL(org.X_WP_PRI_PDS_FLG, 'N')  AS X_WP_PRI_PDS_FLG,

        FROM

        WHERE
            org.OU_TYPE_CD = 'Customer'

BEGIN
    DELETE FROM siebel.EIM_ACCOUNT WHERE if_row_batch_num BETWEEN 3000100 AND 3000199;
    DELETE FROM siebel.EIM_DEFECT  WHERE if_row_batch_num BETWEEN 3000100 AND 3000199;
    COMMIT;

    FOR reg_par IN curr_party LOOP
    BEGIN
        sPartyName    := reg_par.PARTY_NAME;
        sEimRowId     := reg_par.EIM_ROW_ID;
        v_exists      := 0;
        v_updated_cnt := 0;

        FOR reg_rec IN curr_rec LOOP
        BEGIN
            v_exists := 1;

            -- KN-221 AC I: Merchants already set to Y are left unchanged and are NOT re-refreshed
            IF reg_rec.X_WP_PRI_PDS_FLG <> 'Y' THEN
                v_seq := v_seq + 1;

                    ACCNT_BU,

                    reg_rec.PARTY_UID,
                    reg_rec.PARTY_TYPE_CD,
                    reg_rec.NAME,
                    reg_rec.LOC,
                    reg_rec.ACCNT_BI,
                    reg_rec.ACCNT_BU,
                    'Y'
                FROM DUAL
                WHERE NOT EXISTS (
                    SELECT 1 FROM SIEBEL.EIM_ACCOUNT
                    WHERE ROW_ID = reg_rec.PARTY_ID
                      AND IF_ROW_BATCH_NUM BETWEEN 3000100 AND 3000199
                );

                -- 2. Insert updated party into EIM_DEFECT for Role Refresh (wp_update_tra_status.sh)
                INSERT INTO SIEBEL.EIM_DEFECT (
                    IF_ROW_BATCH_NUM,
                    IF_ROW_STAT,
                    ROW_ID,
                    DEFECT_NUM
                )
                SELECT
                    3000100 + FLOOR(v_seq / 5000),
                    'IMPORTED',
                    reg_rec.PARTY_ID,
                    reg_rec.NAME
                FROM DUAL
                WHERE NOT EXISTS (
                    SELECT 1 FROM SIEBEL.EIM_DEFECT
                    WHERE ROW_ID = reg_rec.PARTY_ID
                      AND IF_ROW_BATCH_NUM BETWEEN 3000100 AND 3000199
                );

                v_updated_cnt := v_updated_cnt + 1;
                counter := counter + 1;
                IF counter = 5000 THEN
                    COMMIT;
                    counter := 0;
                END IF;
            END IF;
        END;
        END LOOP;

        IF v_exists = 0 THEN
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'PO_NOT_FOUND_IN_SIEBEL' WHERE ROW_ID = sEimRowId;
        ELSIF v_updated_cnt = 0 THEN
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'SKIPPED_ALREADY_Y' WHERE ROW_ID = sEimRowId;
        ELSE
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'IMPORTED' WHERE ROW_ID = sEimRowId;
        END IF;

    EXCEPTION
        when others then
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'SQL_PROCESSING_ERROR' WHERE ROW_ID = sEimRowId;
            DBMS_OUTPUT.PUT_LINE(sPartyName || ' ' || SQLCODE || ' ' || SQLERRM);
            CONTINUE;
    END;
    END LOOP;
    COMMIT;

END;

exit;
```

*(Removed `EIM_ACCOUNT`; evaluates `sNewDate := trunc(SYSDATE) - 1` once at run start; handles missing or multiple active agreements in `CX_AGREE_ORG` without throwing `NO_DATA_FOUND`; skips already-expired entitlements; triggers Role Refresh in `EIM_DEFECT` only for updated parties)*:
```sql
/*
-------------------------------------------------------------------------------------
-- File: wp_kn221_expire_entlmnt.sql
-- Desc: KN-221 Part II - Expire active Pricing Entitlements with SYSDATE - 1
--       and stage updated parties in EIM_DEFECT for Role Refresh
-------------------------------------------------------------------------------------
*/

SET SERVEROUTPUT ON
SET VERIFY OFF
WHENEVER SQLERROR EXIT FAILURE

DECLARE
    counter       NUMBER(9) := 0;
    v_seq         NUMBER(9) := 0;
    sPartyName    VARCHAR2(50);
    sPartyId      VARCHAR2(15);
    sEimRowId     VARCHAR2(15);
    -- Evaluated once at run start per KN-221 Acceptance Criteria II
    sDate         DATE := trunc(SYSDATE);
    sNewDate      DATE := trunc(SYSDATE) - 1;
    v_exists      NUMBER := 0;
    v_rows_ins    NUMBER := 0;
    v_updated_cnt NUMBER := 0;

    CURSOR curr_party IS
        SELECT TRIM(DIS_NAME) AS PARTY_NAME, ROW_ID AS EIM_ROW_ID
        FROM SIEBEL.EIM_DISEASE_DTL
        WHERE IF_ROW_BATCH_NUM = 3000200;

    CURSOR curr_rec IS
        SELECT /*+ opt_param('hash_join_enabled','true') opt_param('optimizer_mode','all_rows') */
            orgparty.PARTY_UID              AS PARTY_UID,
            orgparty.PARTY_TYPE_CD          AS PARTY_TYPE_CD,
            org.NAME                        AS NAME,
            org.LOC                         AS LOC,
            orgbu.ROW_ID                    AS ACCNT_BI,
            orgbu.NAME                      AS ACCNT_BU,
            org.ROW_ID                      AS PARTY_ID
        FROM
                SIEBEL.S_PARTY   orgparty
        INNER JOIN SIEBEL.S_ORG_EXT org   ON orgparty.ROW_ID = org.PAR_ROW_ID
        INNER JOIN SIEBEL.S_BU      orgbu ON org.BU_ID       = orgbu.ROW_ID
        WHERE
            org.OU_TYPE_CD = 'Customer'
        AND (org.NAME = sPartyName OR org.ROW_ID = sPartyName);

    reg_par curr_party%ROWTYPE;
    reg_rec curr_rec%ROWTYPE;

BEGIN
    DELETE FROM siebel.EIM_ENTLMNT WHERE if_row_batch_num BETWEEN 3000200 AND 3000299;
    DELETE FROM siebel.EIM_DEFECT  WHERE if_row_batch_num BETWEEN 3000200 AND 3000299;
    COMMIT;

    FOR reg_par IN curr_party LOOP
    BEGIN
        sPartyName    := reg_par.PARTY_NAME;
        sEimRowId     := reg_par.EIM_ROW_ID;
        v_exists      := 0;
        v_updated_cnt := 0;

        FOR reg_rec IN curr_rec LOOP
        BEGIN
            v_exists   := 1;
            sPartyId   := reg_rec.PARTY_ID;
            v_rows_ins := 0;
            v_seq      := v_seq + 1;

            -- Stage active Pricing Entitlements for expiration (EFF_END_DT = SYSDATE - 1)
            -- Entitlements with EFF_END_DT already in the past (< sDate) are left unchanged
            -- Merchants with no active agreement in CX_AGREE_ORG insert 0 rows without throwing NO_DATA_FOUND
            INSERT INTO SIEBEL.EIM_ENTLMNT
            (
            IF_ROW_BATCH_NUM,
            IF_ROW_STAT,
            ROW_ID,
            ORG_ACCNT_BI,
            ORG_ACCNT_BU,
            ORG_ACCNT_LOC,
            ORG_ACCNT_NAME,
            PAR_AGREE_ACC_BI,
            PAR_AGREE_ACC_BU,
            PAR_AGREE_ACC_LOC,
            PAR_AGREE_ACC_NAME,
            PAR_AGREE_BI,
            PAR_AGREE_BU,
            PAR_AGREE_NAME,
            PAR_AGREE_REV_NUM,
            ENTL_NAME,
            ORG_EFF_END_DT)
            (SELECT
            3000200 + FLOOR(v_seq / 5000),
            'FOR_IMPORT',
            ENT_ORG.ROW_ID,
            '0-R9NH',
            'Default Organization',
            PARTY.LOC,
            PARTY.NAME,
            '0-R9NH',
            'Default Organization',
            reg_rec.LOC,
            reg_rec.NAME,
            '0-R9NH',
            'Default Organization',
            AGREEMENT.NAME,
            AGREEMENT.REV_NUM ,
            ENT.NAME,
            case
            when (ENT_ORG.EFF_START_DT >= sDate)
            then
            ENT_ORG.EFF_START_DT
            when (ENT_ORG.EFF_START_DT < sDate)
            then
            sNewDate
            End
            FROM
            SIEBEL.S_DOC_AGREE AGREEMENT,
            SIEBEL.S_ENTLMNT_ORG ENT_ORG,
            SIEBEL.S_ENTLMNT ENT,
            SIEBEL.S_ORG_EXT PARTY
            WHERE
            AGREEMENT.ROW_ID = ENT.PAR_AGREE_ID
            AND ENT.ROW_ID = ENT_ORG.AGREE_ID
            AND ENT_ORG.OU_ID = PARTY.ROW_ID
            AND PARTY.ROW_ID = sPartyId
            AND (AGREEMENT.EFF_END_DT is NULL OR AGREEMENT.EFF_END_DT>=sDate)
            AND (ENT_ORG.EFF_END_DT is NULL OR ENT_ORG.EFF_END_DT>=sDate)
            AND ENT.ENTL_TYPE_CD = 'PRICING'
            AND AGREEMENT.ROW_ID IN (
                SELECT AGREE_ID FROM SIEBEL.CX_AGREE_ORG
                WHERE ACCNT_ID = sPartyId AND (END_DT IS NULL OR END_DT >= sDate)
            )
            AND NOT EXISTS (
                SELECT 1 FROM SIEBEL.EIM_ENTLMNT
                WHERE ROW_ID = ENT_ORG.ROW_ID
                  AND IF_ROW_BATCH_NUM BETWEEN 3000200 AND 3000299
            ));

            v_rows_ins := SQL%ROWCOUNT;

            -- Stage targeted party (and child POs if any) in EIM_DEFECT for Role Refresh ONLY if updated
            IF v_rows_ins > 0 THEN
                v_updated_cnt := v_updated_cnt + v_rows_ins;

                INSERT INTO SIEBEL.EIM_DEFECT
                (IF_ROW_BATCH_NUM,
                IF_ROW_STAT,
                ROW_ID,
                DEFECT_NUM)
                SELECT
                3000200 + FLOOR(v_seq / 5000),
                'IMPORTED',
                 org_hier.ROW_ID,
                 org_hier.NAME
                FROM SIEBEL.S_ORG_EXT org_hier
                WHERE (org_hier.ROW_ID = sPartyId OR org_hier.MASTER_OU_ID = sPartyId)
                  AND NOT EXISTS (
                      SELECT 1 FROM SIEBEL.EIM_DEFECT
                      WHERE ROW_ID = org_hier.ROW_ID
                        AND IF_ROW_BATCH_NUM BETWEEN 3000200 AND 3000299
                  );

                counter := counter + 1;
                IF counter = 5000 THEN
                    COMMIT;
                    counter := 0;
                END IF;
            END IF;
        END;
        END LOOP;

        IF v_exists = 0 THEN
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'PO_NOT_FOUND_IN_SIEBEL' WHERE ROW_ID = sEimRowId;
        ELSIF v_updated_cnt = 0 THEN
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'SKIPPED_NO_ACTIVE_ENTLMNT' WHERE ROW_ID = sEimRowId;
        ELSE
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'IMPORTED' WHERE ROW_ID = sEimRowId;
        END IF;

    EXCEPTION
        when others then
            UPDATE SIEBEL.EIM_DISEASE_DTL SET IF_ROW_STAT = 'SQL_PROCESSING_ERROR' WHERE ROW_ID = sEimRowId;
            DBMS_OUTPUT.PUT_LINE(sPartyName || ' ' || SQLCODE || ' ' || SQLERRM);
            CONTINUE;
    END;
    END LOOP;
    COMMIT;

END;
/
exit;
```
